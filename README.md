# PIXEL DUEL

픽셀 1v1 격투 게임. 랜덤 캐릭터 생성 + AI 상대.

## 설치 / 실행

```bash
pip install -r requirements.txt
python main.py
```

기본은 **전체화면**으로 실행됩니다.

| 명령 | 설명 |
|---|---|
| `python main.py` | 전체화면 |
| `python main.py --window` | 창 모드 (2배) |
| `python main.py --no-fullscreen` | 창 모드 (기본값으로 무시보존) |

게임 중 `F11` 로 전체화면/창 모드를 즉시 전환할 수 있습니다.

내부 렌더 해상도는 640x360 고정이고, 실제 화면에는 **균등 비율로 최대한 크게**
확대되어 중앙에 표시됩니다. 가로세로비가 항상 1.778 로 유지되므로 캐릭터가
세로로 늘어지지 않습니다.

| 실제 화면 | 확대율 | 표시 크기 | 점유율 |
|---|---|---|---|
| 1920×1080 | 3.00배 | 1920×1080 | 100% |
| 1600×900 | 2.50배 | 1600×900 | 100% |
| 1440×900 | 2.25배 | 1440×810 | 90% |
| 1280×720 | 2.00배 | 1280×720 | 100% |
| 1024×768 | 1.60배 | 1024×576 | 75% |

확대율이 정수에 정확히 맞으면 정수 배율을 써서 픽셀 선을 유지하고, 그렇지 않으면
분수 배율로 화면을 꽉 채웁니다. 화면이 더 넓은 경우 위아래(또는 좌우)에 검은
여백이 생기는데, 이는 원본 16:9 비율을 지키기 위한 것입니다.

## 구성

```

  fighter.py         전투 엔티티 (상태기계 + 물리 + 히트박스)
  ai.py              AI 상대 (거리 기반 행동 선택)
  character.py       랜덤 캐릭터 생성 (아키타입 + 능력치)
  sprites.py         스프라이트 로딩/측정/애니메이션
  stage.py           무대·HUD 렌더 + 3x5 픽셀 폰트

  simulate.py        AI vs AI 매치 시뮬레이션
```

## 스프라이트 파이프라인

`game/sprites.py` 가 로드 시 알파 실루엣을 측정해 애니메이션을 자동 구성합니다.

1. **픽셀 인식** — 알파 채널에서 실루엣 추출
2. **해상도 정규화** — 실루엣 높이를 `CHAR_H` 로 맞춰 변환. 프레임마다 해상도가
   달라도 (30x56 과 162x122) 캐릭터 크기가 흔들리지 않습니다
3. **앵커 측정** — 머리 중심(x)과 최하단 픽셀(y). 렌더 시 프레임마다 자기 앵커로
   정렬하므로 교체 시 캐릭터가 튀지 않습니다
4. **보행 위상 분류** — 지면에 닿은 발 개수와 보폭으로
   contact / passing / support 를 판별해 프레임 유지 틱을 배분합니다

폴더에 `metadata.json` 을 두면 자동 분석을 덮어쓸 수 있습니다.

```json
{
  "cycle": ["b", "c", "d"],
  "exclude": ["a"],
  "ticks": {"b": 2, "c": 1, "d": 1}
}
```

## 검증

```bash
python tools/shots.py            # 스크린샷 3장 생성
python tools/simulate.py normal 8   # AI 8경기 시뮬레이션
python tools/test_display.py     # 화면 해상도별 확대 배율 확인
```

`shots/` 에 결과 이미지가 저장됩니다.

## 캐릭터

테스트 단계에서는 **양쪽 모두 같은 스프라이트**를 쓰고 능력치만 랜덤입니다.

| 아키타입 | 체력 | 이동 | 파워 | 특징 |
|---|---|---|---|---|
| RUSH | 92 | 1.30 | 0.86 | 빠르고 약함, 사거리 짧음 |
| ALLROUND | 104 | 1.05 | 1.00 | 균형 |
| POWER | 126 | 0.82 | 1.24 | 굵고 셈, 느림 |
| EDGE | 98 | 1.02 | 1.02 | 특화형 |

## 알려진 제약

- **공격 모션 없음**: 공격 중에도 idle/walk 가 반복됩니다. 가용 스프라이트가
  유휴/보행뿐이라 해당합니다. 공격 전용 폴더(`sprites/attack/`)를 추가하면
  `Fighter.anims` 에 자동으로 반영됩니다.
- `a.png` 만 해상도가 낮아(30x56) 나머지 프레임과 픽셀 밀도가 다릅니다.
  원본을 다시 준비하면 해결됩니다.
